
# Spice Delight Restaurant – Restaurant Sales Analytics

## Project Overview
This Power BI project focuses on analyzing restaurant sales data to understand sales performance and business trends through an interactive dashboard.

## Project Objectives
- Analyze restaurant sales performance.
- Understand sales patterns and trends.
- Evaluate key business performance indicators.
- Present insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Power BI
- Data Cleaning
- Data Visualization
- KPI Reporting

## Data Cleaning
- Reviewed and cleaned the restaurant sales dataset.
- Prepared the dataset for analysis.
- Final cleaned dataset contains 1,388 records.

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Orders | 1K |
| Total Quantity Sold | 3K |
| Completed Orders | 805 |
| Cancellation Rate | 20.42% |
| Avg Customer Rating | 3.95 |
| Total Revenue | 407.505K |
